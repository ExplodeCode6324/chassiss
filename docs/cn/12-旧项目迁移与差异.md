# 旧项目迁移与差异

旧项目 v0.x 与当前 v1 是不同协议，不支持自动迁移、dual-write 或 silent
upgrade。关键变化：

- `.chassis/` 控制目录改为签名 Git Transition + 最小 `.chassiss/state.json`；
- 固定 role credential 改为 Key/Grant/Capability/Scope/Limit；
- `bootstrap` 改为 verified `context`；
- Requirements/Architecture/Mission/Tasks 改为 Architecture + 单轮 Taskbook；
- Git 从本地 backend 提升为共享账本和验证对象模型；
- Agent 不再直接操作 Git mutation。

建议迁移流程：

1. 冻结旧项目并做只读导出；
2. Master 明确确认新 Project ID、Root trust anchor 与初始 checkpoint；
3. 把仍有效的结构重新表达为 v1 Architecture；
4. 把当前工作轮重新表达为 Taskbook，重新定义 `writes`、`affects` 和 Checks；
5. 在无 history 的新目录创建 Genesis；
6. 每个 Agent 重新生成 key 与 Grant Request；
7. 不把旧 credential、control event 或 private/local State 放入新 Git history。

逐项架构对照、实现选择和未关闭差距见
[正式差异登记](../12-implementation-differences.md)。

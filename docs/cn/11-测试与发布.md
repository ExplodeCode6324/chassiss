# 测试与发布

本地质量门：

```text
go mod tidy
go test ./...
go test -race ./...
go vet ./...
go build ./cmd/chassiss
```

完整 CLI 生命周期测试创建真实临时 Git repository、Ed25519 keys、signed
Transitions 与 linked worktrees，覆盖：

```text
Genesis → Grant → offline proposal/publish → Task start
→ Work Commit → submit → Review → Integration
→ Taskbook Closure/archive → Architecture update
→ Owner Apply → next Taskbook open → full verify
```

`fixtures/` 提供 14 类跨实现目录。Canonical JSON、digest、Architecture/
Taskbook、State 和 Genesis Reducer vector 由测试直接读取；其余 scenario
manifests 与 repository-backed tests 共同维护。

本地 loopback `git daemon` 测试会启动独立 remote 和两个 checkout，制造并发
Root Grant 与 Authority Transition CAS 竞争，验证 Evidence attempt 2 重算、
并发 Grant 保留，以及可信 clone 后从 Genesis 全量验证。它不连接真实外部服务。

Release build 应注入：

```text
Version
BuildDigest
ReleaseIdentity
```

示例：

```text
go build -trimpath \
  -ldflags "-s -w \
  -X github.com/ExplodeCode6324/chassiss/internal/cli.Version=v0.1.0 \
  -X github.com/ExplodeCode6324/chassiss/internal/cli.BuildDigest=<git-oid> \
  -X github.com/ExplodeCode6324/chassiss/internal/cli.ReleaseIdentity=<builder>" \
  -o dist/chassiss ./cmd/chassiss
```
